# Moduvero — Forros & Acabamentos

Site institucional responsivo para apresentação de forros, divisórias, pisos e drywall, com foco em São Paulo.

## Visualizar

Abra `index.html` no navegador. O site usa HTML, CSS e JavaScript, sem instalação de dependências ou etapa de compilação.

Para servir por HTTP com Python instalado:

```sh
python -m http.server 8080
```

Depois acesse `http://localhost:8080`.

## Recursos

- Navegação adaptada para celular e computador.
- Detalhes das soluções e galeria ampliada de ambientes.
- Formulário que prepara o orçamento e abre o WhatsApp com a mensagem preenchida.
- Atendimento: **(11) 91867-1741**.
- Logo arredondado em PNG transparente e favicon personalizado.

O formulário não armazena dados. O visitante confirma o envio no WhatsApp.

## Arquivos

- `index.html`: conteúdo, metadados e estrutura.
- `styles.css`: identidade visual e adaptação para diferentes telas.
- `app.js`: navegação, galeria, detalhes e orçamento.
- `assets/`: fotografias e símbolo da marca.

## Publicar

Os arquivos podem ser hospedados em qualquer serviço de sites estáticos. Para GitHub Pages, use a branch `main` e a pasta raiz `/` nas configurações de Pages do repositório.
